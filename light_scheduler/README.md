# Light Scheduler

A Home Assistant App that schedules brightness and color temperature for your lights through an intuitive timeline editor.

## Features

- Daily schedules with keyframe-based timelines
- Brightness and color temperature control
- Smooth transitions between keyframes
- In-app UI for schedule management
- Support for ESPHome, WLED, and native Home Assistant lights

## Installation

Install from the Home Assistant Community Store (HACS) or manually from this repository.
